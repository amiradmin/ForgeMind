# Changelog

All notable changes to ForgeMind are documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-01

### Added

- Modular Django and Django REST Framework foundation.
- JWT authentication and custom identity model.
- Organization, plant, area, asset type, and asset APIs.
- Telemetry and industrial-event domain foundations.
- Unified per-asset operational timeline.
- Maintenance requests, plans, and work-order APIs.
- PostgreSQL, Redis, Celery worker, and Celery beat development stack.
- OpenAPI schema with Swagger UI and ReDoc.
- Automated formatting, linting, migration, and test checks in GitHub Actions.
- Contributor guide, issue forms, pull-request template, security policy, support policy, and code of conduct.
- Contributor-friendly issues and GitHub Discussions.
- Vector platform overview separating implemented foundations from planned Industrial AI capabilities.

### Release scope

This is a foundation release for contributors and technical evaluation. Predictive maintenance models, anomaly detection, computer vision, digital-twin integration, and a production frontend remain roadmap items.
